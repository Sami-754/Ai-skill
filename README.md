# Ai-skill

Agent skills, hooks, and rules collection.

## Contents

- `skills/` — reusable agent skills
- `hooks/` — agent hooks
- `rules/` — agent rules (chisle)
- `.skill-lock.json` — skill install lockfile

## Use

Copy into your agents directory:

```bash
cp -r skills hooks rules ~/.agents/
cp .skill-lock.json ~/.agents/  # optional
```
