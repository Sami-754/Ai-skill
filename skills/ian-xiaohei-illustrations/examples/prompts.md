# Prompt Examples

These prompts can be copied directly into Codex.

## Planning only

```text
Use $ian-xiaohei-illustrations and do not generate images yet.
Please analyze where this article is worth illustrating and output a shot list of about 5 images.
For each image, explain:
- where it should go in the article
- the topic of the image
- the core meaning
- the structure type
- what Xiaohei is doing
- suggested elements
- suggested English labels

<paste article>
```

## Article body illustrations

```text
Use $ian-xiaohei-illustrations and generate 4 Xiaohei body illustrations for the article below.
Requirements: 16:9 horizontal, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten English annotations.
Each image should explain only one core structure. Do not make it look like a PPT infographic, and do not make it cute or cartoonish.

<paste article>
```

## Long-form article strategy

```text
Use $ian-xiaohei-illustrations to plan illustrations for this long article.
Do not average the coverage. Only pick cognitive anchor points: core judgment, input/output loop, before-after contrast, common pitfalls, and handoff path.
Default to 6-8 images. Output a shot list first; do not generate images yet.

<paste article>
```

## One idea, one image

```text
Use $ian-xiaohei-illustrations to generate one 16:9 body illustration for this idea:

Trust is not shouted into existence. It is laid down one piece of evidence at a time.

Make the image weird but clean, and make Xiaohei the core actor.
Keep the labels short and in English.
```

## Workflow topic

```text
Use $ian-xiaohei-illustrations to generate one image for:

Turn one raw source into three forms of value: traffic, trust, and conversion.

Do not draw a formal flowchart, and do not reuse the old one-fish-many-uses composition.
Reinvent a new low-tech metaphor, and make Xiaohei perform the core action.
```

## Edit: remove a title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the top-left title "Workflow" and its underline. Keep everything else unchanged.
Do not add any new text or objects.
```

## Edit: increase Xiaohei involvement

```text
Use $ian-xiaohei-illustrations. This image is directionally right, but Xiaohei feels too decorative.
Keep the core idea the same and regenerate it so Xiaohei is the real force driving the structure.
Make the image a little stranger, but keep it pure white, clean, and sparse.
```

## Generate a style set

```text
Use $ian-xiaohei-illustrations to output 5 different Xiaohei illustration styles.
Cover these topics: information overload, product validation, content compounding, solo company, and trust building.
Generate each one separately. Do not combine them into a single image.
```
